# Nutrition-Lifestyle-Analysis
📌 Project Overview

The Nutrition & Lifestyle Insights Dashboard project analyzes how daily habits like diet, exercise, sleep, and hydration affect overall health. Using Microsoft Excel, the project transforms raw data into meaningful insights through pivot tables and an interactive dashboard.

---

📂 Project Structure

nutrition-123.xlsx
│
├── data            → Raw dataset
├── pivot table     → Data summary and analysis
└── dashboard       → Visual insights using charts

📈 Key Insights

Individuals who exercise regularly tend to have a healthier BMI

Proper sleep (7–8 hours) improves overall health patterns

Balanced nutrition supports weight management

Hydration plays an important role in maintaining fitness

Lifestyle habits directly impact long-term health



---

⚠️ Problems Identified

❌ High number of overweight and obese individuals

❌ Low physical activity levels

❌ Poor sleep habits

❌ Imbalanced diet (high calories, low protein)

❌ Inadequate daily water intake



---

💡 Solutions Suggested

✅ Encourage regular exercise (3–5 hrs/week)

✅ Maintain a balanced diet with proper nutrients

✅ Follow a consistent sleep routine (7–8 hrs/day)

✅ Increase daily water intake (2–3 liters)

✅ Track health metrics regularly
